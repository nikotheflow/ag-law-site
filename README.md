# Сайт юриста Александра Гришанина

Статический сайт на Astro 7. На выходе обычный HTML в папке `dist/`, его можно положить на любой хостинг.

## Команды

```bash
npm install        # один раз
npm run dev        # локальный сервер: http://localhost:4321
npm run build      # собрать сайт в dist/
npm run markers    # список незакрытых меток [УТОЧНИТЬ], [ПРОВЕРИТЬ], [КЕЙС]…
```

## Где что лежит

| Что | Где |
|---|---|
| Тексты страниц | `content/pages/**/*.md` (правила и метки — в `content/README.md`) |
| Контакты, реквизиты, меню | `src/data/site.ts` — одно место на весь сайт |
| Шапка, подвал, блок связи, микроразметка | `src/components/` |
| Общий макет страницы (SEO-теги) | `src/layouts/Base.astro` |
| Стили (пока заготовка, не дизайн) | `src/styles/global.css` |
| Исследование, запросы, вопросы Саше | `research/` |

## Как добавить страницу

Создать `.md` в `content/pages/` с frontmatter (`title`, `description`, `h1`, `slug`). Адрес берётся из `slug`. Страница появится сама: в сборке, в sitemap, а если адрес начинается с `/uslugi/`, то и в каталоге услуг. В меню её нужно добавить вручную, в `src/data/site.ts`.

`draft: true` — страница собирается, но закрыта от индексации (`noindex`). Черновики ещё нужно перечислить в `DRAFT_PATHS` в `astro.config.mjs`, чтобы они не попали в sitemap.
