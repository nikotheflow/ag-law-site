# Тексты сайта

Черновики страниц. Каждый файл — одна страница. Вверху метаданные (frontmatter), ниже текст в Markdown. Потом эти файлы почти без изменений пойдут в сборщик сайта.

## Метаданные

```yaml
title:        # <title>, до ~70 символов: главный запрос + город + имя
description:  # meta description, до ~160 символов, с призывом
h1:           # заголовок страницы
slug:         # адрес страницы
query:        # главный запрос из карты (research/03-karta-zaprosov.md)
queries:      # вспомогательные запросы
```

## Метки в тексте

| Метка | Что значит |
|---|---|
| `[УТОЧНИТЬ: …]` | Нужен ответ Саши: цена, часы работы, этаж и т. п. |
| `[ПРОВЕРИТЬ: …]` | Юридический факт, который Саша должен подтвердить: сроки, ставки, номера статей |
| `[КЕЙС: …]` | Место под реальный кейс Саши. Пока пусто, ничего не выдумываем |
| `[ОТЗЫВ]` | Место под реальный отзыв |
| `[ФОТО: …]` | Место под фотографию |
| `[БРЕНД]` | Название, пока Саша не выбрал: «АГ \| юридическая студия» или «Юрист Александр Гришанин» |

## Правила текста

- Говорим от первого лица, от имени Саши, просто и по делу. Так он описывает себя на Харанте: «говорю простым языком, честно оцениваю перспективы».
- **Не пишем «адвокат».** Не обещаем гарантированный результат. Не пишем «лучший» и «№ 1».
- **Цены — только «от».** Сейчас стоят цены с Харанта, их подтвердит Саша.
- **Кейсы и отзывы — только настоящие.** Пока их нет, стоят метки.
- Главный запрос страницы — в title, H1 и первом абзаце. Остальные — в подзаголовках и FAQ, без повторов ради повторов.
